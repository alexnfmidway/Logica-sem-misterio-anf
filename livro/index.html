CAPÍTULO 01

Primeiro, vamos organizar as ideias

Programar é dar instruções claras para resolver um problema. Antes do computador, existe o raciocínio.

Algoritmo é uma receita

Uma receita organiza ingredientes e passos para chegar a um resultado. Um algoritmo faz o mesmo: recebe informações, segue instruções e produz uma resposta.

🥪
Exemplo do dia a dia

Para montar um sanduíche: pegar o pão → passar o recheio → fechar → servir. Se a ordem muda, o resultado também pode mudar.

O caminho de uma solução

ENTRADAIngredientespão + queijo
↓
PROCESSAMENTOSeguir os passosmontar o sanduíche
↓
SAÍDAResultadolanche pronto

Variável

Uma caixinha com nome, onde guardamos um valor que pode mudar. Ex.: temperatura.

#

Constante

Um valor que escolhemos manter fixo durante o cálculo. Ex.: os minutos de uma hora, 60.

Aa

Tipo de dado

Indica que tipo de valor cabe na caixinha: número, texto, verdadeiro ou falso.

IMAGINE A MEMÓRIA COMO UMA ESTANTE

Exemplo em C#C#
string nome = "Ana";
int idade = 16;
bool temIngresso = true;

string guarda texto, int guarda número inteiro e bool guarda true ou false.

CAPÍTULO 02

Passo a passo: sequência e operadores

Na estrutura sequencial, cada instrução acontece em ordem. Operadores ajudam a fazer contas e comparações.

Uma compra no mercado

Você pega dois produtos e calcula o total. Primeiro lê os preços, depois soma e, por fim, mostra o resultado.

  1. 1 Ler os preços
  2. 2 Somar os valores
  3. 3 Exibir o total
MERCADINHO DA ESQUINA
🍎 MaçãsR$ 5,00
🥛 LeiteR$ 6,50
TOTALR$ 11,50
5,00 + 6,50 = 11,50
Aritméticos

+ somar · - subtrair · * multiplicar · / dividir · % resto

Comparação

== igual · != diferente · > maior · < menor · >= maior ou igual

Lógicos

&& E · || OU · ! NÃO

Traduzindo a sequênciaC#
double macas = 5.00;
double leite = 6.50;
double total = macas + leite;
Console.WriteLine($"Total: R$ {total:F2}");

No código, = significa “guarde este valor”. Já == pergunta “estes valores são iguais?”.

CAPÍTULO 04

Repetir sem fazer tudo de novo

Laços de repetição executam um conjunto de passos várias vezes — até a tarefa terminar ou uma condição mudar.

Regar várias plantas

Em vez de escrever “regar a planta” dez vezes, podemos repetir a instrução enquanto houver plantas sem água.

🪴🌱🌿🪴🌱
regar uma↶próxima planta↶até acabar
Repetição com limiteC#
for (int planta = 1; planta <= 5; planta++)
{
    Console.WriteLine($"Reguei a planta {planta}");
}

O for é útil quando sabemos quantas vezes repetir. O while repete enquanto uma condição for verdadeira.

⚠

Evite o laço infinito: confira se alguma coisa muda para que a condição deixe de ser verdadeira. Sem isso, o programa pode repetir para sempre.

CAPÍTULO 05

Listas organizadas: vetores e matrizes

Quando temos muitos valores relacionados, guardá-los juntos deixa o programa mais organizado.

Vetor é uma fileira de gavetas

Um vetor guarda vários valores do mesmo tipo. Cada posição tem um índice. Em C#, a primeira posição é a 0.

notas
índice 08
índice 17
índice 29
índice 36

Matriz é uma tabela

Uma matriz organiza valores em linhas e colunas. Pense nos assentos de uma sala ou em uma tabela de horários.

Col. 0Col. 1Col. 2 Fila 0🪑🪑🪑 Fila 1🪑🪑🪑
Guardar e acessar notasC#
int[] notas = { 8, 7, 9, 6 };
Console.WriteLine(notas[0]); // mostra 8

int[,] assentos = { { 1, 2, 3 }, { 4, 5, 6 } };
Console.WriteLine(assentos[1, 2]); // linha 1, coluna 2

Atenção: acessar uma posição fora do tamanho da lista causa erro. Neste exemplo, os índices das notas vão de 0 a 3.

Funções: dividir para conquistar

Um programa grande fica mais fácil de entender quando separamos tarefas em partes menores e damos um nome a cada uma.

🎈Decorar

✉️Convidar

Uma função tem uma responsabilidade

Assim como cada pessoa pode cuidar de uma parte da festa, cada função resolve uma tarefa específica. Ela pode receber dados e devolver um resultado.

Por que isso ajuda?
O código fica mais legível, partes podem ser reutilizadas e fica mais simples encontrar onde corrigir um problema.
Uma função que calculaC#
static double CalcularMedia(double nota1, double nota2)
{
    return (nota1 + nota2) / 2;
}

double media = CalcularMedia(8, 10);
Console.WriteLine(media); // 9

CalcularMedia recebe duas notas (parâmetros), faz o cálculo e devolve a média com return.

CAPÍTULO 07

Registros: dados que andam juntos

Às vezes, uma coisa tem características de tipos diferentes. Um registro agrupa essas informações em uma estrutura com significado.

Uma ficha de estudante

Nome é texto, idade é número e matrícula também pode ser texto. Um registro junta os campos que descrevem a mesma pessoa.

👩🏽‍🎓
ESTUDANTEMarina CostaIdade: 17 anosTurma: 2º ano
✓
Representando a fichaC#
class Estudante
{
    public string Nome { get; set; }
    public int Idade { get; set; }
    public string Turma { get; set; }
}

var estudante = new Estudante
{
    Nome = "Marina Costa",
    Idade = 17,
    Turma = "2º ano"
};
Resumo: vetor é uma coleção de valores parecidos; registro é um conjunto de campos que descreve uma entidade; uma matriz organiza coleções em linhas e colunas.
